PRIVACY

Minimal data. Useful signals.

Domain Doctor is designed to provide public web diagnostics without requiring an account. Limited aggregate analytics are used to understand how the service is used and where it can be improved.

What Domain Doctor collects

Domain Doctor uses Umami Cloud for privacy-focused aggregate usage analytics. This can include page views, approximate visitor counts, referral sources, and limited product events such as whether a scan was started, completed, or blocked.

Analytics are configured to honor Do Not Track and to exclude URL query strings and URL fragments.

What Domain Doctor does not intentionally collect

  • No Domain Doctor account or user profile is required.
  • Submitted hostnames are not attached to analytics events.
  • URL query strings containing submitted hostnames are excluded from analytics.
  • Scan results are not sent to analytics as event properties.
  • Domain Doctor does not use analytics for behavioral advertising.
  • Domain Doctor does not sell personal information.

Diagnostic requests

When you submit a public hostname, Domain Doctor processes that hostname to perform the requested DNS, TLS, HTTP, HTTPS, redirect, and security header checks. The hostname necessarily passes through the web server as part of the request.

Like most Internet services, infrastructure such as the reverse proxy, hosting provider, or application server may create operational logs for security, reliability, and troubleshooting purposes.

Third-party analytics

Aggregate analytics are provided by Umami Cloud. Domain Doctor does not enable session replay for product discovery analytics.

Changes

This page will be updated if Domain Doctor begins collecting materially different information, adds accounts, or introduces other features that change how user data is handled.
